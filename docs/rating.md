# Рейтинг игроков

План: три части. Сейчас готова первая.

1. **По балансу** (готово): в каталоге кнопка «Рейтинг» открывает топ-30 по числу аконов. Строка игрока (имя, аватар из профиля, баланс) лежит в Firestore в `ratings/<uid>`; игрок обновляет её сам, когда меняется его баланс, имя или аватар (раз в 15 секунд при изменении, вместе с облачной синхронизацией). Читать рейтинг могут только вошедшие в Google.
2. **Победы онлайн** (готово, первая версия): в меню каждой игры с онлайн-режимом (Ятзи, блэкджек, покер Чожук, «Морской бой») постоянно видна плашка «Победы онлайн» с топ-5 этой игры (внизу на телефоне, в углу на компьютере). Победа записывается с устройства победителя: «Ятзи» — партия доиграна (не «остальные вышли»), блэкджек — раздача выиграна, за столом не меньше двух игроков, покер — выигрыш на вскрытии, «Морской бой» — потоплен весь флот. Таблица хранится в `ratings_wins/<игра>/rows/<uid>`.
3. **Быстрые победы в одиночных играх** (позже): например «Сапёр», у каждого уровня свой топ «самый быстрый выигрыш», обновляется каждый день. Потом ещё 2–3 разных топа.

Честность: баланс и победы записывает сам браузер игрока, поэтому рейтинги честны лишь настолько, насколько честны игроки ([кошелёк](wallet.md)). Правила базы не дают прибавить за одну запись больше одной победы, но повторять запись можно. Настоящая защита — считать победы на сервере игр (нужен служебный ключ Firebase), это отдельный этап.

## Правила Firestore

Добавьте в блок `match /databases/{database}/documents` рядом с `users` (полный текст правил: [вход через Google](google-login.md)):

```
match /ratings/{uid} {
  allow read: if request.auth != null;
  allow create, update: if request.auth != null && request.auth.uid == uid
    && request.resource.data.balance is int && request.resource.data.balance >= 0
    && request.resource.data.name is string && request.resource.data.name.size() <= 20;
}
```

Для побед онлайн добавьте ещё один блок:

```
match /ratings_wins/{game}/rows/{uid} {
  allow read: if request.auth != null;
  allow create: if request.auth != null && request.auth.uid == uid && request.resource.data.wins == 1;
  allow update: if request.auth != null && request.auth.uid == uid
    && request.resource.data.wins == resource.data.wins + 1;
}
```

Пока правил нет, окно рейтинга пишет «Рейтинг пока недоступен», а синхронизация и игры работают как раньше.
