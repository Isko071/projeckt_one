# Рейтинг игроков

План: три части. Сейчас готова первая.

1. **По балансу** (готово): в каталоге кнопка «Рейтинг» открывает топ-30 по числу аконов. Строка игрока (имя, аватар из профиля, баланс) лежит в Firestore в `ratings/<uid>`; игрок обновляет её сам, когда меняется его баланс, имя или аватар (раз в 15 секунд при изменении, вместе с облачной синхронизацией). Читать рейтинг могут только вошедшие в Google.
2. **Победы онлайн** (позже): у каждой игры своя таблица в меню самой игры.
3. **Быстрые победы в одиночных играх** (позже): например «Сапёр», у каждого уровня свой топ «самый быстрый выигрыш», обновляется каждый день. Потом ещё 2–3 разных топа.

Честность: баланс считается в браузере игрока, поэтому рейтинг по балансу честен лишь настолько, насколько честны игроки ([кошелёк](wallet.md)). Победы онлайн лучше считать на сервере игр.

## Правила Firestore

Добавьте в блок `match /databases/{database}/documents` рядом с `users` (полный текст правил: [вход через Google](google-login.md)):

```
match /ratings/{uid} {
  allow read: if request.auth != null;
  allow create, update: if request.auth != null && request.auth.uid == uid
    && request.resource.data.balance is int && request.resource.data.balance >= 0
    && request.resource.data.name is string && request.resource.data.name.size() <= 20;
}
```

Пока правил нет, окно рейтинга пишет «Рейтинг пока недоступен», а синхронизация и игры работают как раньше.
