# Личный кабинет владельца

Страница `/admin/` на сайте (https://isko071.github.io/projeckt_one/admin/). В каталоге на неё ссылки нет, поисковикам она закрыта (`noindex`). Показывает игроков, которые входили через Google. Гости без входа в базу не попадают, поэтому их в списке нет (их считает статистика посещений, см. ниже).

## Что видно (этап 1)
- Итоги: сколько игроков всего, сколько были за сутки и за неделю, сколько новых за сутки и за неделю, сколько партий сыграно.
- Таблица игроков: ник, время регистрации, последний визит, баланс аконов, партии по играм («Ятзи», «Сапёр», «Блэкджек») и всего. Сортировка по любой колонке, поиск по нику или коду игрока, кнопка «Обновить». До 1000 игроков.
- Партия считается, когда игра начата: в блэкджеке это раздача, в «Ятзи» и «Сапёре» одна игра. Счётчик ведётся с момента выхода этой версии, прежние партии не восстанавливаются.
- Время регистрации берётся из данных аккаунта Google/Firebase и записывается при следующем заходе игрока (у тех, кто больше не заходил, пока «—»). Последний визит обновляется при каждой загрузке страницы после входа.

## Как включить доступ (один раз)
Читать записи других игроков правила базы по умолчанию запрещают. Откройте Firebase Console → Firestore Database → Rules и добавьте в блок `match /users/{uid}` строку для вашего аккаунта (полный текст правил: [вход через Google](google-login.md)):
```
allow read: if request.auth != null && request.auth.token.email == 'ВАШ_АДРЕС@gmail.com' && request.auth.token.email_verified == true;
```
Подставьте адрес своего Google-аккаунта, нажмите «Опубликовать». Адрес остаётся только в правилах в консоли и не попадает в репозиторий. Откройте `/admin/`, войдите этим аккаунтом. Любой другой аккаунт получит отказ от самой базы (страница лишь показывает ответ), так что подделать доступ нельзя.
