# Личный кабинет владельца

Страница `/admin/` на сайте (https://isko071.github.io/projeckt_one/admin/). В каталоге на неё ссылки нет, поисковикам она закрыта (`noindex`). Показывает игроков, которые входили через Google. Гости без входа в базу не попадают, поэтому их в списке нет (их считает статистика посещений, см. ниже).

## Что видно (этап 1)
- Итоги: сколько игроков всего, сколько были за сутки и за неделю, сколько новых за сутки и за неделю, сколько партий сыграно.
- Таблица игроков: ник, время регистрации, последний визит, баланс аконов, партии по играм («Ятзи», «Сапёр», «Блэкджек») и всего. Сортировка по любой колонке, поиск по нику или коду игрока, кнопка «Обновить». До 1000 игроков.
- Партия считается, когда игра начата: в блэкджеке это раздача, в «Ятзи» и «Сапёре» одна игра. Счётчик ведётся с момента выхода этой версии, прежние партии не восстанавливаются.
- Время регистрации берётся из данных аккаунта Google/Firebase и записывается при следующем заходе игрока (у тех, кто больше не заходил, пока «—»). Последний визит обновляется при каждой загрузке страницы после входа.

## Как включить доступ (один раз)
Читать записи других игроков правила базы по умолчанию запрещают. Откройте Firebase Console → Firestore Database → Rules и добавьте в блок `match /users/{uid}` строку для вашего аккаунта (полный текст правил: [вход через Google](google-login.md)):
```
allow read: if request.auth != null && request.auth.token.email == 'ВАШ_АДРЕС@gmail.com' && request.auth.token.email_verified == true;
```
Подставьте адрес своего Google-аккаунта, нажмите «Опубликовать». Адрес остаётся только в правилах в консоли и не попадает в репозиторий. Откройте `/admin/`, войдите этим аккаунтом. Любой другой аккаунт получит отказ от самой базы (страница лишь показывает ответ), так что подделать доступ нельзя.

## Временная правка баланса
В таблице у баланса кнопка ✎: введите новое число (0…10 000 000), правится только поле баланса в записи игрока. Нужно разрешить запись своему аккаунту в правилах Firestore (в блок `match /users/{uid}`, адрес так же держите только в консоли):
```
allow update: if request.auth != null && request.auth.token.email == 'ВАШ_АДРЕС@gmail.com' && request.auth.token.email_verified == true;
```
Игрок получит новый баланс при следующем входе или синхронизации, если на его устройстве после прошлой синхронизации ничего не менялось; если менялось, он увидит запрос «какой прогресс оставить». Функция временная: когда она перестанет быть нужна, уберите кнопку (`data-edit` в `admin/admin.js`) и правило.

## Вкладка «Сервер» (этап 2)
Показывает то, что видит сервер столов: сколько игроков онлайн, сколько столов сейчас, сколько создано, входов, начатых игр, ошибок и отказов, время работы, рекорды; список живых столов (код, игра, состояние, кто за столом) и последние 300 событий (создан стол, вошёл, вышел, начата игра, стол удалён, ошибка, отказ в доступе). Обновляется каждые 10 секунд.
- Данные в памяти сервера: после перезапуска или засыпания на бесплатном Render счётчики и журнал обнуляются. Если сервер спал, запрос будит его, ответ может прийти через минуту.
- Отдаёт данные только сервер, и только владельцу: адрес `GET /admin/stats`, нужен токен Google. Разрешены лишь аккаунты из переменной `ADMIN_EMAILS` на Render (через запятую) с подтверждённой почтой. Без этой переменной доступа нет ни у кого.

### Настройка (один раз)
Render → сервис `igroteka-server` → Environment → Add: `ADMIN_EMAILS` = ваш адрес Google (тот же, что в правилах Firestore) → Save, сервер перезапустится сам.

## Посещения сайта (этап 3)
Статистику, включая гостей, страны, устройства и страницы, считает Cloudflare Web Analytics: бесплатно, без cookie. В кабинете это ссылка «Посещения сайта ↗» (открывается панель Cloudflare). Скрипт подключён на каталоге и страницах игр, но не на `/admin/`, поэтому ваши заходы в кабинет не считаются.

### Включение (один раз)
1. На https://dash.cloudflare.com войдите (или зарегистрируйтесь) → Web Analytics → Add a site → в поле Hostname впишите `isko071.github.io` → Done. Переносить домен или менять DNS не нужно.
2. Cloudflare покажет код вида `<script defer src='https://static.cloudflareinsights.com/beacon.min.js' data-cf-beacon='{"token": "…"}'></script>`. Нужен только токен из `token`.
3. Впишите токен в `shared/firebase-config.js` (`CF_ANALYTICS_TOKEN`) и поднимите версию (`node tools/set-version.js <N>`) или пришлите его мне. Пока токен пустой, ничего не загружается. Когда он задан, в подвале каталога появляется строка «Считаем обезличенную статистику посещений».
