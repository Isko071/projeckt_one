# Поиск в Google и Яндексе

## Что уже сделано на сайте
- У главной и у каждой игры свой заголовок и описание (то, что видно в выдаче), канонический адрес, превью для Telegram и WhatsApp (картинка 1200×630, `assets/og.jpg` и `games/<игра>/og.jpg`) и разметка schema.org (сайт и игры).
- Карта сайта: `sitemap.xml` (главная и все игры).
- Внизу главной обычные ссылки на все игры.
- Всё это вписывает `node tools/seo.js [адрес сайта]`: тексты правятся там же. Новая игра — добавить её в список `PAGES` в `tools/seo.js` и сделать картинку превью.

## Что сделать владельцу (один раз)
1. **Google Search Console** (search.google.com/search-console) → «Добавить ресурс» → «Префикс URL» → `https://isko071.github.io/projeckt_one/` → способ подтверждения «HTML-тег». Скопировать значение `content="…"` и вписать в `VERIFY.google` в `tools/seo.js`, запустить `node tools/seo.js`, влить. Нажать «Подтвердить».
2. Там же: «Файлы Sitemap» → `sitemap.xml` → «Отправить». Затем «Проверка URL» → адрес главной → «Запросить индексирование».
3. **Яндекс Вебмастер** (webmaster.yandex.ru) → «Добавить сайт» → тот же адрес → «Мета-тег». Значение `content` — в `VERIFY.yandex`, запустить `node tools/seo.js`, влить, подтвердить. «Индексирование → Файлы Sitemap» → добавить `https://isko071.github.io/projeckt_one/sitemap.xml`.
4. Страницы появляются в поиске обычно за несколько дней — пару недель. Помогают ссылки на сайт из соцсетей и Telegram.

`robots.txt` для сайта по адресу `isko071.github.io/projeckt_one/` положить нельзя (он читается только из корня домена); он и не нужен — по умолчанию разрешено всё, а личный кабинет закрыт метатегом `noindex`.
