# Дорожная карта и открытые вопросы

Работа идёт небольшими шагами: ИИ готовит изменение, проверяет тестами и в браузере и сразу открывает pull request, владелец вливает его. После каждого шага — короткий отчёт.

## Что сделано

- **Каталог** с обложками, главным постером и адресом игры в ссылке (`#id`); светлая и тёмная темы; профиль (имя и аватар).
- **10 игр:** Кости, Сапёр, Блэкджек, Покер: Чожук, Морской бой, Мины, Дурак, Шашки, 2048, Блоки. В каждой — окно «Помощь»: коротко и с примерами картинкой.
- **Кошелёк:** аконы, серия дней, бонус дня, награды и дневные пределы, журнал, рекорды: [кошелёк](wallet.md). Для вошедших игроков баланс считает сервер: [серверный кошелёк](server-wallet.md).
- **Вход через Google** (Firebase) и облачное сохранение прогресса: [вход через Google](google-login.md).
- **Онлайн-столы** на своём сервере (Node.js на Render): блэкджек, кости, покер, морской бой, дурак, шашки; закрытые столы по коду и ссылке, боты по выбору создателя, ставки, чат: [онлайн-столы](online-tables.md), [сервер столов](game-server.md).
- **Рейтинг:** по балансу, по победам (в каждой игре плашка лидера), по быстрым победам в «Сапёре» и по очкам в 2048 и «Блоках».
- **Личный кабинет владельца** (только просмотр): [кабинет](admin.md).
- **Поиск:** заголовки и описания, текст об игре прямо в HTML, карты сайта `sitemap.xml` и `sitemap.txt`, страница 404, Google Search Console: [поиск](seo.md).
- **Хостинг:** Cloudflare Pages (https://partejka.pages.dev/); прежний адрес на GitHub Pages переводит на новый вместе с прогрессом гостя.

## Открытые вопросы

| Вопрос | Состояние |
|---|---|
| Название | «Партейка» совпадает с названием других игровых сайтов (`partejka.ru`, `parteika.ru`, `partejki.ru`); решить, оставить его или выбрать более узнаваемое |
| Новые игры | См. [идеи игр](game-ideas.md) |
| Достижения | Предлагались, решение не принято |
| Второй язык | Тексты уже в словарях, добавлять ли английский — позже |
| Сервер без засыпания | На бесплатном Render сервер засыпает после простоя; платный тариф — от 7 $ в месяц |

## Риски

- **Хранилище браузера.** У гостей прогресс живёт в одном браузере; вход через Google переносит его в облако.
- **Бесплатный сервер.** Первое подключение к онлайну после простоя ждёт до минуты, пока сервер проснётся.
- **Игры с аконами.** Только виртуальная валюта, никаких платежей и реальных ставок.
