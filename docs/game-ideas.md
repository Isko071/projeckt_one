# Идеи новых игр

Условия: игра простая в правилах, интересная на 5–10 минут, делается за несколько этапов на нашем каркасе (логика в `logic.js` с тестами, интерфейс, подключение к каталогу, [инструкция](adding-a-game.md)). Здесь мои предложения; ваши два варианта добавим рядом, потом выберем порядок.

## Одиночные

### 1. «Слова» (угадай слово, как Wordle)
- **Правила:** загадано слово из 5 букв, 6 попыток. После каждой попытки буквы подсвечиваются: на месте, есть в слове, нет в слове. Экранная клавиатура показывает уже использованные буквы.
- **Почему интересно:** «слово дня» одно для всех (выбирается по дате, без сервера), его хочется отгадывать каждый день: хорошо сочетается с серией дней и бонусом в кошельке. Есть и бесконечный режим со случайным словом.
- **Что нужно:** список слов (загадываемые ~1500 частых существительных и ~10 000 допустимых для ввода), хранится в репозитории; без сервера. Буква «ё» считается как «е».
- **Награда:** победа даёт аконы по числу использованных попыток, в рамках дневного лимита наград (как в «Сапёре»).
- **Размер:** 4 этапа (словарь и логика с тестами, интерфейс и клавиатура, слово дня и серия, подключение к каталогу). Самый средний по объёму.

### 2. «2048»
- **Правила:** поле 4×4, свайп или стрелки сдвигают все плитки, одинаковые числа сливаются; цель — получить 2048 (и можно играть дальше).
- **Почему интересно:** понятна за 10 секунд, затягивает, подходит для телефона (свайпы). Рекорд очков хранится в таблице рекордов кошелька.
- **Что нужно:** только логика поля (чистая, легко покрывается тестами), анимации слияния, отмена одного хода как приятная мелочь.
- **Награда:** за плитки 512, 1024, 2048 (в рамках дневного лимита).
- **Размер:** 3 этапа. Самая простая из предложенных.

Запасные варианты: «Найди пары» (память, 3 размера поля), «Змейка», «Пробирки» (сортировка цветов по уровням).

## Онлайн

### «Морской бой» (2 игрока)
- **Правила:** у каждого поле 10×10 и флот (кораблей 1×4, 2×3, 3×2, 4×1), расстановка вручную или кнопкой «случайно». Игроки по очереди стреляют по чужому полю, «ранил / убил / мимо», при попадании ход остаётся. Побеждает тот, кто потопил весь флот.
- **Почему подходит для нашего сервера:** в игре есть скрытая информация (чужие корабли). Сервер сам ведёт стол и не показывает противнику расстановку, поэтому подсмотреть нельзя (на старой схеме с хостом в браузере это было бы возможно). Столы, коды и ссылки-приглашения, закрытые столы и чат уже готовы.
- **Одиночный режим:** против компьютера (простой бот стреляет случайно, сильный добивает раненый корабль и считает вероятности) можно добавить вторым этапом, он же нужен для обучения новичка.
- **Награда:** победа онлайн даёт аконы в рамках дневного лимита, чтобы не получался «обмен победами» между друзьями.
- **Размер:** 5 этапов (логика поля и стрельбы с тестами, интерфейс расстановки, онлайн-стол на сервере, бот, подключение к каталогу).

Запасной вариант покрупнее: «Дурак» (2–6 игроков, самая популярная карточная игра у нас; боты нужны обязательно, правил больше, объём примерно как у блэкджека).
