# Идеи новых игр

Условия: игра простая в правилах, интересная на 5–10 минут, делается за несколько этапов на нашем каркасе (логика в `logic.js` с тестами, интерфейс, подключение к каталогу, [инструкция](adding-a-game.md)).

## Уже сделаны

Кости, Сапёр, Блэкджек, Покер: Чожук, Морской бой, Мины, Дурак, Шашки, 2048, Блоки. Что в каждой и какие награды — в [README](../README.md#игры).

## Ещё не сделаны

### «Слова» (угадай слово)
- **Правила:** загадано слово из 5 букв, 6 попыток. После каждой попытки буквы подсвечиваются: на месте, есть в слове, нет в слове. Экранная клавиатура показывает уже использованные буквы.
- **Почему интересно:** «слово дня» одно для всех (выбирается по дате, без сервера), хорошо сочетается с серией дней. Есть и бесконечный режим.
- **Что нужно:** список слов (~1 500 загадываемых и ~10 000 допустимых), хранится в репозитории. «Ё» считается как «е».
- **Награда:** по числу использованных попыток, в рамках дневного предела.
- **Размер:** 4 этапа.

### Запасные
«Найди пары» (память, 3 размера поля), «Змейка», «Пробирки» (сортировка цветов по уровням).
