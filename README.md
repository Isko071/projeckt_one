# Игротека

Сайт с небольшими браузерными играми: одиночными, против ботов и онлайн с друзьями. Одна валюта на весь сайт, **аконы** (виртуальные, настоящих денег нет), общий профиль, серия дней, рейтинг игроков и вход через Google для сохранения прогресса.

Адрес: https://isko071.github.io/projeckt_one/. Репозиторий называется `projeckt_one`.

## Игры

| Игра | Режимы | Награды и лимиты |
|---|---|---|
| **Ятзи** | против компьютера (лёгкий, сильный), вдвоём на одном устройстве, онлайн 2–6 игроков | за победу над компьютером 100 (лёгкий) и 250 (сильный), общий предел одиночных наград 1 500 в день |
| **Сапёр** | новичок 9×9 (10 мин), любитель 12×12 (24), эксперт 16×16 (40); рекорды по времени | за победу 100 / 250 / 300; у эксперта дневного предела нет |
| **Блэкджек** | с ботом (против дилера), онлайн 2–5 игроков по коду или ссылке, боты трёх характеров | ставок нет: победа 250, блэкджек 400, ничья и проигрыш без награды; до 3 000 в день |
| **Покер: Чожук** | с ботами (2–6 мест), онлайн 2–6 игроков по коду или ссылке | играют на реальные аконы (вход 50 / 100 / 250); против ботов за день можно выиграть до половины баланса на начало дня, потом игра без аконов; онлайн предела нет |
| **Морской бой** | с ботом (лёгкий, эксперт), онлайн на двоих; радар, подлодка и бомбардировщик | за победу над ботом 500; до 2 500 в день на лёгком и 5 000 на эксперте; онлайн без награды |
| **Мины** | одиночная: поле 5×5, от 1 до 24 мин | 1–4 мины: 50 за клетку; 5–24: первая клетка 50 + 10 за каждую мину сверх четырёх, каждая следующая на 20 дороже; мина сжигает накопленное и списывает штраф (500 при 1–10 минах, 200 при 11–24); дневного предела нет |

Новые игры планируются: [идеи](docs/game-ideas.md).

## Аконы, серия и рейтинг

- **Старт:** 5 000 аконов. Сбросить или купить нельзя.
- **Серия дней:** день засчитывается, когда вы начали хотя бы одну партию. Бонус дня: 500 в первый день серии, плюс 250 за каждый следующий, потолок 2 000. Разовые бонусы за серию: 7 дней +1 000 и 14 дней +2 000, дальше только бонус дня.
- **Рейтинг:** топ игроков по балансу в меню игр (имя и аватар берутся из профиля).
- **Вход через Google:** прогресс (профиль, аконы, серия, рекорды) сохраняется в облаке и открывается на любом устройстве.
- Все числа и правила: [кошелёк](docs/wallet.md). Кошелёк считается в браузере, серверной защиты от правки баланса пока нет.

## Как устроен проект

Статический сайт без сборки и зависимостей: открывается из `index.html`. Онлайн-столы ведёт небольшой сервер на Node.js (`server/`, развёрнут на Render). Все тексты лежат в словарях, язык сейчас русский. Светлая и тёмная темы.

```
index.html     каталог игр: шапка, главный постер, сетка
catalog/       каталог, профиль, кошелёк, рейтинг в меню
games/         games.js (реестр игр) и по папке на игру: логика, интерфейс, стили, тексты, обложка, тесты
shared/        общее: тема, хранилище, тексты, профиль, кошелёк, рейтинг, облако, движок онлайн-столов, чат
server/        сервер онлайн-столов (Node.js, WebSocket)
admin/         личный кабинет владельца
locales/       словарь русских текстов
assets/        логотип и обложки
tests/         автотесты общих модулей
tools/         set-version.js: версия сайта в адресах скриптов и стилей
docs/          документация
```

## Запуск и тесты

Для одиночных игр достаточно открыть `index.html` в браузере. Онлайн работает через уже запущенный сервер (адрес в `shared/firebase-config.js`); как запустить свой: [сервер столов](docs/game-server.md).

Тесты (Node.js 20+, зависимостей нет):

```
node --test
```

Тесты сервера: `cd server && npm install && npm test`.

После правок скриптов и стилей обновите версию сайта: `node tools/set-version.js <число>` (она сбрасывает кэш браузера).
