# Игротека (репозиторий projeckt_one)

Сайт с каталогом небольших браузерных игр. Готовы три игры: «Ятзи», «Сапёр» и «Блэкджек» (у «Ятзи» и «Блэкджека» есть онлайн-столы), дальше планируется покер, а потом ещё игры.

> Статус: **каталог, профиль, кошелёк с аконами, вход через Google и три игры готовы** («Ятзи», «Сапёр», «Блэкджек»). Онлайн-столы работают без своего сервера (Firestore, хост — браузер создателя). Осталось: покер и ещё одна игра, обложки и название платформы, настоящие аккаунты и рейтинг. Всё, что ещё не решено, собрано в [дорожной карте](docs/roadmap.md) как открытые вопросы.

Платформа называется **«Игротека»** (название и логотип приняты). Адрес сайта: https://isko071.github.io/projeckt_one/. Репозиторий пока называется `projeckt_one`; его можно переименовать в настройках GitHub (история и ссылки сохранятся).

## Идея

1. Пользователь открывает сайт и видит **только список игр** — сетку карточек-постеров.
2. Нажимает на карточку — **игра занимает главный постер** (большой блок вверху с обложкой, названием и описанием), а остальные игры остаются в списке ниже.
3. Кнопка «Играть» запускает игру. Из игры всегда можно вернуться в каталог.

Отправная точка для вида и поведения — главная страница [isko-three](https://github.com/Isko071/isko-three) (шапка, большая карточка с постером и описанием, внизу карусель постеров, клик по постеру меняет главную карточку). Мы берём идею, но делаем её удобнее (см. [«Что улучшаем по сравнению с isko-three»](#что-улучшаем-по-сравнению-с-isko-three)).

## Что решено

| Тема | Решение |
|---|---|
| Список игр | Сетка карточек-постеров |
| Главный постер | Обложка, название, описание, кнопка «Играть» |
| Игры | Ятзи, сапёр и блэкджек (готовы), покер; ещё одна позже |
| Технически | Статический сайт без сборки: каталог + отдельная папка на каждую игру |
| Шапка | Логотип и название, кнопка смены темы, аватар/профиль |
| Вход | Сначала локальный профиль (имя и аватар в браузере), настоящие аккаунты позже и безопасно, через готовый сервис |
| Деньги | Только игровые фишки, без реальных денег и платежей |
| Стиль | Как нынешний «Ятзи»: мягкий, зелёный акцент, светлая и тёмная темы |
| Язык | Русский; тексты сразу хранятся в словаре, чтобы позже добавить другие языки без переписывания |
| Репозиторий | Новый репозиторий под платформу |
| Обложки игр | Рисуются в Claude Design, мы получаем макет и верстаем |

## Запуск и тесты

Откройте `index.html` в браузере. Сервер, сборка и установка зависимостей не нужны.

Тесты общих модулей (нужен Node.js 20+, зависимостей нет):

```
node --test tests/*.test.js games/*/tests/*.test.js
```

## Как мы работаем

- Работа идёт по этапам; после каждого этапа отдельный коммит и короткий отчёт.
- К следующему этапу переходим только после подтверждения.
- Pull request создаётся и вливается только по явной просьбе.
- Для игр пишутся автотесты чистой логики (`node --test`), как в «Ятзи».

## Что улучшаем по сравнению с isko-three

В isko-three хорошая идея экрана, но есть вещи, которые мы сознательно делаем иначе:

- **Вход.** В isko-three «вход» — имитация: страница проверяет только наличие cookie `token`, которую может поставить кто угодно. У нас на первом этапе честный локальный профиль без пароля, а настоящая защита — позже через готовый сервис аккаунтов, а не самописную проверку.
- **Адаптивность.** Там размеры заданы жёстко (фон высотой 1080 px, отступ в шапке 449 px), на телефоне это ломается. У нас вёрстка подстраивается под любой экран (как главное меню «Ятзи»: без прокрутки там, где это возможно).
- **Смена главной карточки.** Там данные фильма хранятся в `data-*` атрибутах карточек и меняются местами при клике. У нас данные игр лежат в одном описании (реестре), а вид строится по нему.
- **Состояние в адресе.** Выбранная игра отражается в ссылке (например `#yahtzee`), так что кнопка «Назад» и ссылка на конкретную игру работают.
- **Доступность.** Карточки — настоящие кнопки с фокусом и подписями, управление с клавиатуры, учёт `prefers-reduced-motion`.
- **Тема.** Светлая и тёмная, переключатель в шапке; выбор общий для каталога и всех игр.
